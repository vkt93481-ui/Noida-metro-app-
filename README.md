# Noida Metro (Android App)

Offline-first Android app for the **Noida Metro Aqua Line (NMRC)** with route planning, official fare calculation, live GPS station tracking, and arrival alarms.

## How to Get the `.apk` File (No Android Studio Needed)
1. Create a new repository on [GitHub](https://github.com/new) (e.g., `noida-metro-app`).
2. Extract this ZIP and upload all files (including the hidden `.github` folder) to the repository.
3. Open the **Actions** tab in your GitHub repository.
4. Click **Build Noida Metro APK** -> wait ~3 minutes -> download **NoidaMetro-APK** under **Artifacts**.
5. Unzip and install `NoidaMetro.apk` on your Android phone.

## Or Build Locally in Android Studio
1. Open the `NoidaMetro` folder in Android Studio.
2. Let Gradle sync.
3. Click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
